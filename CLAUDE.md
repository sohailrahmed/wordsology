# Wordsology site: working notes

Static Astro site for wordsology.org (ASCP exam prep since 2012), hosted on Cloudflare Pages.
Every push to `main` deploys automatically. Page text lives in `src/content/pages/*.md`.

## How Sohail wants changes handled

- **Preview first.** Show screenshots (desktop and phone) before anything goes to `main`.
  Work on a `preview/...` branch; merge to `main` only when he says to push.
- Ask before restructuring a chart (splitting, merging, removing). Don't read a question as a request.

## Charts: the house rules

- **Big flowcharts** (branching identification trees like Gram-positive cocci): one SVG image,
  shown wide on desktop (figures over 1800 px wide get the `wide` class automatically) with
  tap/pinch-to-zoom on phones. Don't make separate phone and desktop versions unless analytics
  later show phones are the majority of traffic.
- **Tables and simple groupings** (HACEK, parasites): build as HTML in the Markdown page so text
  reflows on phones and is searchable.
- **Keep Sohail's memory drawings.** They're deliberate teaching hooks, not decoration: hippo for
  HIPPurate, orange arrow for CAMP, staph grape cluster, strep chain, lancet-shaped pneumococci,
  the "What am I?" cartoon, the vanquishmycin needle. Redraw them as vectors when possible;
  never drop them.
- **Paired tests stay stacked**, one above the other (PYR over 6.5% NaCl, PYR over Bacitracin,
  Microdase over Bacitracin, Hippurate over CAMP), with one result sign per test, stacked the
  same way (+ over +, − over −, + over S, − over R).
- **Organism names:** current name first, older name in parentheses when exams may still use it,
  e.g. *Giardia duodenalis* (*lamblia*), *Cystoisospora* (*Isospora*) *belli*. Keep names the
  medical community hasn't adopted (e.g. *Diphyllobothrium latum*).
- Flag any content you think is wrong instead of silently changing it; Sohail is an MLS(ASCP).

## Chart sources

- `public/charts/microbiology/gram-pos-cocci.svg` is generated by a Python script
  `tools/gpc_chart.py`; regenerate with `python3 tools/gpc_chart.py public/charts/microbiology/gram-pos-cocci.svg`.
- Every chart figure gets an anchor from its file name (trailing digits dropped), e.g.
  `/high-yield-notes-2/microbiology/#gram-pos-cocci`.
